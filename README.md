# Python Projects 🎮🐍

A collection of small Python projects created to practice programming concepts, game development, and working with external libraries.

## Projects

### 🐦 Flappy Bird

A simple recreation of the classic Flappy Bird game built with Python and Pygame.

**Features:**
- Player-controlled bird movement
- Collision detection
- Randomly generated pipes
- Score system
- Game over and restart functionality

**Technologies:**
- Python
- Pygame

---

### 🐍 Snake

A classic Snake game implemented in Python using Pygame.

**Features:**
- Keyboard-controlled snake movement
- Random food generation
- Collision detection
- Score tracking
- Increasing snake length

**Technologies:**
- Python
- Pygame

---

### 🎵 Music Playlist

A small Python application for creating and managing a music playlist.

**Features:**
- Add songs to a playlist
- Manage playlist entries
- Practice working with Python data structures and program logic

**Technologies:**
- Python
